# Hospital Management System

A menu-driven Hospital Management System built using **Python and SQLite**. The system is designed to manage important hospital operations such as patients, doctors, appointments, billing, and administrative functions.

## Technologies Used

* Python
* SQLite
* Git
* GitHub
* Visual Studio Code

## Main Features

* Patient management
* Doctor management
* Appointment management
* Billing management
* Receptionist functions
* Administrator functions
* SQLite database
* Menu-driven system
